# Relation Net 关系档案

一个轻量、可迁移的人物关系网。用人物卡片、关系连线和阵营区域，整理书籍、游戏与现实中的人物。

**原生 HTML + CSS + JavaScript + SVG，零运行依赖，无后端、无数据库、无构建步骤。**

## 从故事生成关系图：AI Skill

仓库附带 [故事转关系图 skill](skills/story-to-relation-net/SKILL.md)。把**故事文本 + `SKILL.md`** 一起交给支持长文本或附件的 AI，即可让它提取人物、别名、有向／无向关系和阵营，输出符合 Relation Net v1 格式的 JSON；导入应用后就会显示为可编辑的关系图。

## 运行

这是完整离线源码版，包含页面、样式、脚本和原创演示数据。需要事先安装 Python 3（仅用于启动本地静态服务器）。先完整解压 ZIP：

- Windows：双击 `start-windows.bat`。
- macOS：运行 `start-macos.command`；若系统不允许直接运行，在终端执行下面的命令。
- Linux / 通用方式：

```sh
python3 start-local.py
```

启动后会自动打开 `http://127.0.0.1:8765/`，使用期间保留启动窗口。服务只监听本机，不向局域网开放。每次使用相同的地址和浏览器，才能继续读取之前的图谱；关闭启动窗口不会删除数据。可用 `--no-browser` 关闭自动打开浏览器。

也可以自行启动静态服务器：

```sh
python3 -m http.server 8080 --directory dist
```

然后打开 `http://localhost:8080`。Windows 也可使用 `py -m http.server 8080 --directory dist`。可以改用任意静态服务器；ES 模块需通过 HTTP 服务加载，请勿直接双击 HTML 文件。

### Skill使用方法

1. 打开上面的技能文件，下载 `SKILL.md` 或复制其完整内容。
2. 在 AI 对话中附上该文件和故事正文，说明要覆盖的章节。技能正文包含完整格式，不需要 AI 能运行代码，也不依赖某个特定平台。
3. 请 AI 按技能生成 `.relation-net.json` 文件。如果只能输出文字，将完整 JSON 保存为 UTF-8 文件；不包含 Markdown 的代码围栏或额外解释。
4. 打开 Relation Net，在左侧底部点击“导入”，选择该文件。导入会新增独立图谱，不覆盖现有图谱。
5. 查看人物、关系与证据笔记，需要时点击“一键整理”调整初始布局，再手动修正 AI 的理解。

可直接复制这个请求，附上 `SKILL.md` 和故事：

```text
请按附件 SKILL.md，把我提供的故事生成 Relation Net v1 关系图 JSON。
只使用所提供文本，合并有依据的别名，保留关系方向，并在笔记中记录依据。
请输出可下载的 故事人物关系.relation-net.json；若不能创建文件，只输出完整 JSON。
```

在已安装该技能、支持 `$技能名` 调用的 AI 环境中，也可直接使用 `$story-to-relation-net` 并附上故事。若只有普通聊天界面，直接上传或粘贴技能正文即可。

需要续写图谱时，同时提供旧 JSON 和新章节，并明确要求“保留原有信息，合并新章节，输出完整图谱”。技能会要求保留已有 ID、布局、自定义关系类型及角色属性；导入合并结果仍会创建一张新图谱。需要“亲情”等独立关系类型，或“特殊能力”等角色模板字段时，也可在请求中说明，内容仍应有故事依据。

## 支持功能

- 全界面中英切换：侧栏底部切换，自动记住选择；首次根据浏览器语言决定。菜单、表单、提示、帮助和教程均提供英文，默认示例与教程练习中的人物、介绍、关系和阵营始终使用中文。
- 首次打开显示互动教程：高亮真实角色与按钮，实际点击、编辑、连线和整理后自动继续，最后查看阵营与备份入口。支持上一步、跳过单步、退出及重看；手机为提示预留底部空间，键盘弹出时精简提示。

- 多图谱，区分书籍、游戏、现实与其他类型。
- 左侧工作空间、阵营和人物档案可独立折叠，默认全部展开；折叠不改变当前图谱或筛选。
- 人物档案与笔记的新增、编辑和删除。
- 角色头像上传、拖动裁剪和缩放，支持触屏与方向键；未上传或移除后显示姓名首字。头像显示在图谱、人物列表、档案及直接关系中，随图谱保存、撤销与导入导出。
- 卡片名称、别名、身份与关系标签按实际宽度省略，悬停显示完整文字，详情中保留原文。
- 有向 / 无向关系、关系标签、关系笔记。内置合作 / 冲突类型；选择“其他…添加自定义类型”可填写亲情、师徒等独立类型，保存后在当前图谱中复用，并使用单独的类型标识与颜色。旧“其他”关系保留，可逐条重新分类。
- 点击人物聚焦一度关系，详情面板跳转相关人物。聚焦只计算本人及直接关系，自动缩放不低于 85%；关系范围过大时以选中人物为中心，拖动画布查看其余人物。退出聚焦恢复之前的视角。
- 从人物详情点击“添加关系”，直接在画布选取终点；悬停预览、高亮两端人物，在侧栏填写关系后保存，Esc 取消。右上角仍使用完整关系表单。
- 人物拖动、画布平移、滚轮缩放、适应画布。手动缩放范围为 25%–300%，点击缩放百分比恢复 100%；窗口尺寸变化保留缩放。
- 一键整理整张图谱：根据连接自动排布，拉开卡片间距、分开独立关系群，并比较候选布局以减少连线交叉与穿过卡片的情况。一次撤销即可恢复。
- Shift + 点击或“多选”选择人物，组建阵营；人物可属于多个阵营。
- 阵营成员编辑、成员筛选、阵营关系概览。阵营视图支持直接拖动和一键整理，独立保存阵营位置并支持撤销；点击阵营查看成员，连线从阵营边缘连接。
- 自动保存至当前浏览器、当前图谱 JSON 导入导出。
- 最近 40 次数据修改撤销（Ctrl / Cmd + Z），包括删除与布局调整。
- 手机和平板窄屏使用抽屉导航、加大触控按钮、可展开的底部详情面板，以及单列表单；手机横屏改用侧边详情。
- 触屏支持单指平移、双指缩放、点按查看。需要拖动人物或阵营时，先开启“移动节点”；双指缩放和取消手势不会误存节点移动。
- 窄屏自动定位最低为 75%，聚焦最低为 85%；可手动缩小查看全图。详情打开时保留缩放控件，输入关系时可使用全屏编辑区域。
- 处理屏幕安全区与软键盘可用高度；支持表单标签与键盘选择。

## 数据与迁移

数据保存在 `localStorage` 的 `relation-net:v1` 键中。应用没有图谱上传接口，也没有账号、跨设备同步或多人编辑。**从在线网站迁移到离线版前，请在原网站逐张导出 JSON，再到离线版导入。** 清除浏览器数据、切换浏览器、域名或端口都不会自动迁移图谱。

本地存储没有额外加密，也不按 ChatGPT 账号隔离：共用同一浏览器配置的人可能看到相同图谱。导出 JSON 包含人物、笔记、关系和自定义属性，请勿将私人图谱提交到源码仓库。支持 WebMCP 的浏览器可让浏览器代理调用当前图谱读取工具；交给代理处理的数据按代理平台规则处理。普通浏览器运行本应用不需要这些接口。

导出包含当前图谱的全部人物、关系、阵营与坐标。导入新增独立图谱，不覆盖旧图谱；相同人物可以有多条不同关系。JSON 版本为 1，导入会校验引用、重复 ID、颜色、坐标和大小（每图谱最多 500 人物 / 3,000 关系 / 100 阵营；单文件 10 MB）。这是导入安全上限，不代表大规模图谱的性能保证；当前定位是数十至数百个人物的个人图谱。大量数据受浏览器存储配额限制，保存失败时会明确提示导出。

阵营可带可选的 `x`、`y` 坐标，两者需同时提供，为绝对值不超过 100,000 的有限数字。旧 v1 文件无需添加这些字段，应用会提供默认排列；拖动或整理后自动保存。阵营坐标独立于人物坐标，整理两种视图互不影响。

自定义类型使用可选的 `board.relationTypes` 数组，每项为 `{ "id": "type-family", "name": "亲情", "color": "#8874a6" }`，关系的 `kind` 引用该 `id`。每张图谱最多 100 项，名称最多 60 字符；同一名称复用已有类型。内置 ID `cooperation`、`conflict`、`other` 继续有效，旧 v1 JSON 不需要修改。新增类型与关系一同保存、撤销和导出。

同一图谱不支持多标签页并发编辑；请在一个标签页中修改。JSON 备份是普通明文文件，可能含有你输入的人物笔记，应按个人需要保管。

## 角色头像

新增或编辑人物时点击“上传头像”，选择 PNG、JPG、WebP 或 GIF（最大 10 MB / 4000 万像素），拖动图片与调整缩放后点击“使用此头像”，最后保存档案。取消裁剪保留此前的头像；取消整个编辑不保存任何头像改动。GIF 使用解码时的静态画面。

图片只在设备内处理，裁剪为 256 × 256 的静态头像，通常压缩为 WebP。可选的角色 `avatar` 字段为 PNG、JPEG 或 WebP 的 Base64 data URL，上限 128 KiB 字符，不引用外部网址；旧 v1 JSON 可直接使用。头像随 JSON 一同导出。浏览器空间仍有限，保存失败时请导出备份。

## 角色模板

在左侧“人物档案”中点击“编辑角色模板”，为当前图谱添加自定义文本属性，例如“特殊能力”。保存后，已有角色和新增角色的编辑表单、档案详情都会显示这些属性；每个角色分别填写，支持多行文本。模板只属于当前图谱，不影响其他工作空间。属性可改名或删除，改名保留内容；删除时会提示受影响的角色数量，保存后可撤销恢复。

v1 JSON 新增可选的 `board.characterTemplate` 数组，每项为 `{ "id": "field-ability", "name": "特殊能力" }`。角色的可选 `attributes` 对象按属性 ID 保存值，例如 `{ "field-ability": "操纵雾气\n在雨天增强" }`。每张图谱最多 30 个属性，属性名称最多 60 字符、同一模板中不重名，每项内容最多 10,000 字符；空内容可以省略。属性 ID 须唯一且稳定，改名不更换 ID。导入会检查属性引用，避免丢失内容；旧 v1 文件无需增加这些字段。

## 语言与教程

侧栏底部、问号左侧的 `ENG` / `中文` 切换语言；手机先打开左上角菜单。点击问号进入操作指南，可再次打开“新手教程”。语言与教程的完成状态分别保存在 `relation-net:language`、`relation-net:tutorial:v1`，与图谱数据分开，JSON 导出格式仍为 v1。

切换语言仅更新界面，不翻译或改写已有的人物名称、笔记、自定义关系类型等内容，也不重置草稿、选中人物、布局、缩放或撤销历史。新生成示例与教程练习资料始终为中文，不随界面语言改变；保存过的旧英文默认示例只有在原始文字与关系未被编辑时才自动恢复中文，保留坐标、颜色和自定义属性。自行创建或编辑过的图谱保持原样。JSON 中的图谱类别和内置类型 ID 保持兼容，界面按当前语言显示。

`i18n.js` 使用中文文案作为键，集中维护英文映射。静态界面通过 `data-i18n` 标记，动态界面使用 `t(key, values)`；请勿对用户文本自动调用翻译。教程步骤与临时练习图谱集中在 `tutorial.js`。练习使用真实编辑器和画布，但所有修改仅存在内存中，不会写入浏览器保存的图谱；退出恢复原图谱、撤销历史、选中状态、缩放与未保存的关系草稿。刷新或关闭页面也不会把练习数据保存进去。高亮层在 `spotlight.js` 中通过真实控件的屏幕位置跟随移动、缩放与滚动；键盘 Tab 在目标控件和教程按钮之间移动，Esc 退出。新增文案请一并补充字典，并运行测试检查覆盖和插值参数。

## 设计与后续扩展

视觉借鉴游戏关系网中的档案卡片、关系线和阵营区域。“雾港档案”中所有人物与关系为原创虚构演示。

SVG 负责画布与图形，可直接修改样式；`model.js` 不依赖 DOM，可复用到其他 UI。布局支持手动调整和一键整理，阵营边界由成员卡片的凸包形成。自动整理使用有迭代上限的力导向排布、卡片避让和独立关系群装箱；计算过程中分段让出主线程，不需要第三方图形库或服务器。只有坐标会被修改，整理期间若图谱已有新编辑则丢弃旧计算结果。

所有画布文字使用原生 SVG，随同一场景变换移动和缩放，不再使用 `foreignObject` 嵌入 HTML。文本按浏览器测得的实际宽度省略，完整文字保留在提示中；字体加载后重新测量，重复绘制复用结果。

自动整理是一种近似优化，不能保证所有连线都不交叉，也不能保证关系文字永不重叠。图谱很密集时，可继续用点击人物聚焦或手动微调。添加 IndexedDB 或服务端同步时，可独立替换对应模块，无须引入完整后端。

在支持 `document.modelContext` 的浏览器中，会注册可选的 WebMCP 工具 `read_relation_graph` 和 `focus_relation_character`。常规浏览器忽略它，不影响应用。该实验性接口未在真实支持环境中验证。

当前版本已进行 JavaScript 语法、静态资源引用、数据完整性及模拟触控交互检查，包括双指缩放、误拖保护、撤销、面板切换、中英状态保持和教程流程；尚未进行真实手机浏览器端到端和视觉验收。
